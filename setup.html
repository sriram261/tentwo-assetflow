Required setup

Connect this website to Supabase.

This ZIP is ready for GitHub Pages, but you must create a Supabase project and paste your project URL and anon key in assets/js/config.js.

1

Create project

Create a free Supabase project. Save the Project URL and anon public key.

2

Run SQL

Open Supabase SQL Editor and run supabase/schema.sql from this ZIP.

3

Update config

Open assets/js/config.js and paste your Supabase URL and anon key.

4

Deploy to GitHub

Upload this folder to GitHub and enable GitHub Pages from repository settings.

5

Create users

Use the dashboard sign up form, or create users manually from Supabase Auth.

6

Start testing

Upload AMF files, add assets, edit rows, and check shared data with your friends.
