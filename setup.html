Setup guide

Connect AssetFlow to your Supabase backend.

Use this page as a quick checklist. Create the Supabase project, run the SQL file, add your project URL and public key, then publish the site with GitHub Pages.

1

Create project

Create a Supabase project for AssetFlow and save the Project URL and public key.

2

Run SQL

Open Supabase SQL Editor and run supabase/schema.sql to create the tables.

3

Update config

Open assets/js/config.js and paste the Supabase URL and public key.

4

Deploy to GitHub

Upload the site files to GitHub and enable GitHub Pages from repository settings.

5

Create users

Create the approved users in Supabase Auth before sharing the dashboard link.

6

Start testing

Upload AMF files, add assets, edit rows, search records, and export reports.
